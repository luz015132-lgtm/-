# 五十音闪练 v2.6｜公开发布版

一款帮助日语初学者记忆五十音的离线学习工具。通过随机抽取、主动回忆、四选一测试、错题强化和艾宾浩斯复习计划，帮助使用者逐步建立对平假名与片假名的长期记忆。

## 主要功能

- 支持平假名、片假名和平片混合练习
- 支持按行自由选择抽取范围
- 收录基础假名、浊音、半浊音和常用拗音，共104项
- 提供“看字回忆”和“四选一”两种训练方式
- 四选一优先生成相近读音和同类型干扰项
- 随机抽取自动减少短时间内的过度重复
- 错题和薄弱假名自动提高出现概率
- 原创正误反馈音效
- 针对线性马达设计的多级震动反馈
- 支持蓝紫、珊瑚和薄荷三套界面主题
- 主题颜色可同步更换应用图标
- 完全离线运行，无广告、无账号、无联网权限

## 艾宾浩斯智能复习

软件会根据每个假名的练习结果单独安排复习时间：

- 答错后约10分钟重新巩固
- 答对后依次进入1天、2天、4天、7天、15天和30天复习间隔
- 再次答错会降低记忆等级并缩短复习间隔
- 到期内容自动进入“复习”页面
- 开启“智能复习优先”后，普通训练也会优先照顾到期内容

## 学习统计

软件会分别记录每个假名的学习情况，包括：

- 累计练习次数
- 答对次数
- 答错次数
- 历史错误率
- 当前记忆等级
- 下一次复习时间
- 高频错误和薄弱假名
- 今日练习数量与累计正确率

“今日练习”按照手机本地日期计算，每天零点后自动建立新一天的统计。


## 系统要求

- Android 7.0及以上
- 当前版本仅支持Android
- HarmonyOS NEXT和iOS暂不支持直接安装

## 安装方法

1. 在下方“Assets”中下载：

   `KanaSprint-v2.6-.apk`

2. 在Android手机上打开APK。

3. 如果系统提示“未知来源应用”，选择允许本次安装。

从旧版本升级时可以直接覆盖安装，原有学习记录会继续保留。


## 隐私与权限

五十音闪练只申请震动权限，用于操作和正误反馈。

软件没有以下权限：

- 网络访问
- 通讯录
- 定位
- 相机
- 麦克风
- 手机存储

练习记录、错题和复习计划仅保存在本机应用空间，不上传服务器，也不与第三方共享。软件不包含广告SDK、统计SDK、账号系统或后台网络服务。

用户可以在设置页面清零学习数据，卸载应用也会删除本机记录。
